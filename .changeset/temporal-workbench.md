Add the Temporal workbench. When the host passes a `temporalUrl`, Studio shows a Temporal service with screens for Workflow Types, Workflow IDs, Executions, one run with its Event History, Attention, Schedules, Task Queues, Workers, and Cluster & Shards. It works against a standard Temporal server and against slate-temporal-next, and hides what a server does not support.
