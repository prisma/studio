Refresh Studio's visual design with Prisma brand colours and Eclipse styling: DM Sans/DM Mono type, the official Prisma wordmark, an inset page card on a Console-matching canvas, quieter toolbars and controls, shared column badges, a Console-style canvas zoom bar, a subtle Prism-ray loading line, an in-cell "Copied" confirmation and a calmer date/time editor. Hosts should load DM Sans and DM Mono; Studio falls back to the system font otherwise.
